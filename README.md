# 3Dto2DVerify

> **3D 도면 기반 2D 카메라 자동 정밀 제작 검증 시스템**

**설계한 대로 만들어졌는가** — 사람 없이, 자동으로, 정밀하게 답합니다.

---

## 한 줄 요약

STEP 파일(3D 도면)을 입력하면, 라인에 설치된 2D 카메라가 제조품을 촬영하고,  
AI가 설계 치수와 실제 제품을 비교해 **Pass / Fail을 자동 판정**합니다.

---

## 사업 구조

```
설계사 / 제조사 (3rd party)
      │  STEP 도면 제공 + 제조품 투입
      ▼
┌─────────────────────────────┐
│     3Dto2DVerify 검증 라인  │
│                             │
│  📐 CAD 도면 → 2D 투영      │
│  📷 카메라 → 부품 촬영      │
│  🔍 자동 정렬 + 치수 측정   │
│  ✅ Pass / Fail 판정        │
└─────────────────────────────┘
      │  검증 리포트 (mm 단위 오차, 합격 여부)
      ▼
고객사 품질 관리 대시보드
```

## 타겟 시장

- **정밀 기계 가공** — CNC 선반·밀링 가공품 치수 검증
- **전자 부품** — PCB 하우징, 커넥터, 사출 성형품
- **자동차 부품** — 티어 2~3 협력사 납품 전 전수 검증
- **항공·방산** — 고공차 부품 + 완전한 검사 이력 추적

## 로드맵

**Phase 1 (0~6개월)** — MVP  
STEP → 2D 투영, 카메라 캘리브레이션, 치수 측정, Pass/Fail 판정, 파일럿 PoC

**Phase 2 (6~12개월)** — 제품화  
웹 대시보드, PDF 성적서, REST API (ERP/MES 연동), 다면 검증

**Phase 3 (12~24개월)** — 확장  
멀티카메라 6면 검증, 컨베이어 인라인 연동, SaaS, 해외 진출
