# 회사 컨셉 상세

## 문제 정의

현대 제조업에서 **"설계한 대로 만들어졌는가"** 를 확인하는 작업은 여전히 사람에게 의존한다.

- 숙련 검사원이 캘리퍼스·CMM으로 부품을 일일이 측정
- 전수 검사가 아닌 샘플링(5~10%)에 의존 → 불량 출고 위험 상존
- 검사원마다 기준이 달라 재현성 부족
- 수기 기록 → 이력 추적 어려움

## 솔루션

3D 도면(STEP 파일)을 시스템에 등록하면 **2D 카메라 + AI**가 자동으로 검증한다.

### 핵심 원리

```
3D 도면 ──────→ 2D 투영 이미지 (정면/배면/측면)
                        │
카메라 촬영 ────→ 부품 이미지
                        │
              자동 정렬 + 치수 비교
                        │
              Pass / Fail / Warning
```

3D 도면에서 각 면의 **윤곽과 치수**를 자동으로 추출하고,  
카메라로 촬영한 실제 부품 이미지와 **mm 단위**로 비교한다.

---

## 비즈니스 구조

### 역할 분담

| 주체 | 역할 |
|---|---|
| **설계사** (3rd party) | STEP / IGES / DXF 도면 제공 |
| **제조사** (3rd party) | 도면대로 부품 제작 |
| **3Dto2DVerify** | 제작 결과가 도면과 일치하는지 자동 검증 |

3Dto2DVerify는 설계도 하지 않고 제조도 하지 않는다.  
오직 **"검증"** 만 한다 — 그것을 완전히 자동화한다.

---

## 고객 여정

```
1. 고객이 STEP 파일 업로드 (웹 또는 API)
2. 시스템이 자동으로 검증 기준 생성 (수동 셋업 없음)
3. 현장 카메라 설치 (당사 엔지니어 반나절)
4. 부품 라인 투입 → 실시간 자동 검증 시작
5. 대시보드에서 Pass/Fail 현황 확인
6. 불합격품 → 알림 + 라인 I/O 신호로 자동 분리
```

---

## 정확도 목표

| 부품 크기 | 위치 정확도 | 치수 정확도 |
|---|---|---|
| 소형 (< 50mm) | ±0.05mm | ±0.03mm |
| 중형 (50~200mm) | ±0.10mm | ±0.05mm |
| 대형 (200~500mm) | ±0.20mm | ±0.10mm |

---

## 하드웨어 구성

검증 스테이션 1대 기준:

- 산업용 2D 카메라 1~2대 (GigE / USB3)
- 돔 조명 또는 링라이트 (부품 소재에 따라 선택)
- 미니 PC (i7급, 16GB RAM)
- 라인 I/O 인터페이스 (불합격 신호 출력)

3D 스캐너·CMM 등 고가 장비 불필요.

---

## 경쟁 우위

**Cognex, Keyence** 등 기존 2D 비전 시스템과의 차이:

- 기존: 검사 항목을 **수동으로 티칭** (모델당 수시간)
- 3Dto2DVerify: **STEP 파일만 등록하면 자동** (모델당 수분)

**CMM, 3D 스캐너**와의 차이:

- 기존: 수천만~수억원 장비, 전문 운용 인력 필요
- 3Dto2DVerify: 카메라 1~2대, 설치 후 무인 운용
