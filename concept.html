How It Works

5단계 자동 검증 파이프라인

STEP 파일 하나면 셋업 완료. 이후는 시스템이 알아서 판정합니다.

📐
STEP 01

CAD 도면 입력

3rd party의 STEP / IGES / DXF 도면을 시스템에 등록

→
🖼️
STEP 02

2D 투영 자동 추출

3D 도면에서 정면·배면·측면 윤곽 이미지를 자동 생성

→
📷
STEP 03

카메라 촬영

→
🔍
STEP 04

정밀 매칭

→
✅

공차 기준으로 합격 여부 즉시 판정 + 리포트 자동 발행

Value Proposition

왜 3Dto2DVerify인가

기존 검사 방식의 한계를 기술로 해결합니다.

🤖

완전 무인 검증

숙련 검사원 없이 카메라와 AI가 24시간 전수 검사. 야간·주말 라인 중단 없음.

📏

mm 단위 정확도

2D 카메라로 ±0.05mm 수준 치수 측정. 고가 CMM·3D 스캐너 없이 동등 정확도.

⚡

5초 안에 판정

부품 1개당 검증 시간 5초 이내. 수동 측정(5~30분)과 비교 불가한 속도.

🔗

즉시 ERP 연동

REST API로 기존 MES/ERP에 검사 결과 실시간 전송. 별도 소프트웨어 불필요.

📊

100% 추적성

모든 검사 결과 자동 기록. 부품 시리얼별 이력 조회 및 PDF 성적서 자동 발행.

🎯

셋업 불필요

STEP 파일만 등록하면 자동으로 검증 기준 생성. 수동 티칭·프로그래밍 없음.

Competitive Advantage

기존 방식과 비교

Roadmap

제품 로드맵

단계적으로 검증하고 확장합니다.

Phase 1
0 – 6개월

MVP — 핵심 검증 엔진

  • STEP 파일 → 2D 투영 자동 추출
  • 카메라 캘리브레이션 자동화 (픽셀→mm 변환)
  • 에지 기반 이미지 정렬 + 치수 측정
  • Pass / Fail 판정 + JSON 리포트
  • 파일럿 고객 1~3사 PoC
Phase 2
6 – 12개월

제품화 — 운영 플랫폼

  • 웹 대시보드 (실시간 검증 현황 + 트렌드)
  • PDF 검사 성적서 자동 생성
  • REST API (ERP / MES 연동)
  • 정면 + 배면 동시 다면 검증
  • 공차 프로파일 관리 UI
Phase 3
12 – 24개월

확장 — SaaS · 글로벌

  • 멀티카메라 6면 동시 검증
  • 컨베이어 인라인 연동 (I/O 신호로 불량품 자동 분리)
  • 불량 원인 분류 AI (치수 / 가공 / 조립)
  • 클라우드 SaaS 전환
  • 일본·독일 정밀 제조 시장 진출
