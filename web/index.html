Investment Thesis

제조 품질 검사는 여전히 사람과 고가 장비에 묶여 있습니다

중소 제조사는 CMM, 3D 스캐너, 숙련 검사원 사이에서 비용과 속도를 타협합니다. 3Dto2DVerify는 이미 존재하는 CAD 데이터를 검사 기준으로 바꾸고, 저비용 카메라로 치수 오차를 자동 판정하는 소프트웨어 계층을 만듭니다.

Problem 수동 샘플링 검사

검사원 역량에 따라 결과가 달라지고, 전수 검사가 어려워 불량 유출 리스크가 남습니다.

Wedge 2D 카메라 기반 진입

고가 3D 장비보다 빠르게 설치하고, 특정 부품군부터 라인별 반복 매출을 만들 수 있습니다.

Moat CAD 기준 자동화

STEP 도면에서 검증 기준을 생성해 고객별 세팅 시간을 줄이고 운영 데이터를 축적합니다.

Revenue SaaS + API + 온프레미스

중소 제조사는 구독, 대형 고객은 API 과금, 보안 고객은 온프레미스 라이선스로 확장합니다.

Product Concept

도면, 카메라, 판정 리포트를 하나의 검증 라인으로 연결합니다

상면과 하면을 별도 검사 레인으로 처리한 뒤 자동 모델 체커에서 최종 형상 검증과 치수 판정을 수행하는 구조입니다.

Go-to-Market
